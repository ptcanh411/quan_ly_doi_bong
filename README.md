# Quản Lý Quỹ & Điểm Danh FC 6H Sáng Chủ Nhật

Hệ thống theo dõi quỹ, điểm danh và chia tiền sân tự động cho đội bóng FC 6H.

## Tính năng chính:
- Bảng ma trận theo dõi thành viên & trạng thái nộp quỹ.
- Điểm danh và tự động chia đều tiền sân cho các thành viên có mặt.
- Chọn mức giá nạp quỹ linh hoạt & tạo mã VietQR tự động.
- Lịch sử nạp/dùng chi tiết của từng thành viên.
- Phân quyền Admin (Mật khẩu: `ptcanh411`) và Người dùng.

## Chạy cục bộ:
```bash
python server.py
```
Mở trình duyệt: `http://localhost:8000`

## Triển khai Render:
- Start command: `python server.py`
